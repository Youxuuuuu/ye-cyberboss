# 任务状态入口

权威状态说明：[`murmurlane-stack/docs/workflow/triage-status.md`](../../../murmurlane-stack/docs/workflow/triage-status.md)

唯一 Tracker：[`murmurlane-stack/tracker`](../../../murmurlane-stack/tracker)

- 每个任务必须有 `Repo` 和 `Status`。
- 跨仓库任务使用 `Repo: both`。
- 未确定归属时使用 `Status: needs-triage`。
- 完整规则以 `murmurlane-stack` 为准。
