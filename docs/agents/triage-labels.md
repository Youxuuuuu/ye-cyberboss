# 任务状态入口

权威状态说明：本地 [`../murmurlane-stack/docs/workflow/triage-status.md`](../../../murmurlane-stack/docs/workflow/triage-status.md)；GitHub：[main](https://github.com/Youxuuuuu/murmurlane-stack/blob/main/docs/workflow/triage-status.md)。

唯一 Tracker：本地 [`../murmurlane-stack/tracker`](../../../murmurlane-stack/tracker)；GitHub：[main](https://github.com/Youxuuuuu/murmurlane-stack/tree/main/tracker)。

- 状态为 `needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`completed`、`wontfix`。
- `completed` 需要完成条件、提交、自动验证、基线失败与人工验收证据。
- 未确定归属时使用 `Status: needs-triage`；`Repo: both` 只按实际跨边界变化使用。
- 完整规则以 `murmurlane-stack` 为准。
